# 🪔 Diwali Sales Analysis — Exploratory Data Analysis

An Exploratory Data Analysis (EDA) project on Diwali sales data using Python to understand customer purchasing patterns, sales trends, and factors influencing revenue.

## 📌 Project Overview

This project analyzes Diwali sales data to identify patterns in customer demographics, purchasing behavior, product categories, occupations, states, marital status, and gender.

The analysis was performed using Python and popular data analysis and visualization libraries.

## 🎯 Objectives

- Analyze overall sales and customer purchasing behavior
- Identify the most valuable customer groups
- Analyze sales across different states
- Compare purchasing patterns by gender
- Analyze sales based on age groups
- Identify popular product categories
- Analyze the relationship between occupation and purchasing behavior
- Find useful business insights from the dataset

## 🛠️ Technologies & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🔍 Data Analysis Performed

### Data Cleaning
- Checked dataset structure
- Identified missing/null values
- Removed unnecessary columns
- Handled missing data
- Checked data types
- Prepared the dataset for analysis

### Exploratory Data Analysis

The project explores:

- Gender-wise sales
- Age-group-wise sales
- Marital-status-wise sales
- State-wise sales
- Occupation-wise sales
- Product-category-wise sales
- Customer purchasing patterns

## 📊 Visualizations

The analysis uses different visualizations including:

- Bar charts
- Count plots
- Histograms
- Distribution plots
- Category comparisons

These visualizations help identify trends and patterns within the dataset.

## 💡 Key Insights

The analysis provides insights into:

- Which customer groups contribute most to sales
- Which states generate higher sales
- Purchasing differences between male and female customers
- Which age groups have higher purchasing activity
- Which occupations contribute more to sales
- Which product categories are more popular
